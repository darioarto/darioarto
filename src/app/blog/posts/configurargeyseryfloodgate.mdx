# Definitions and uses
First, a quick overview of what each plugin is and what it is used for.

## What is GeyserMC?
GeyserMC is a proxy that allows Minecraft Bedrock players (on mobile, consoles or Windows) to join servers based on the Java Edition. It is not a server in itself, but rather a translator between the Java and Bedrock editions of the game. Its main job is to make the data packets sent by a Bedrock player compatible with the Java server, so both can play together even though they are on different platforms. It is ideal for networks or public servers that want to reach a much wider community without running a separate Bedrock server or Bedrock proxy.

## What is Floodgate?
Floodgate is an add-on for GeyserMC that lets Minecraft Bedrock players join your Java server without owning a Minecraft Java Edition account. In short, it removes the need to sign in with a Java account and allows players to join with just their Microsoft account (the one they normally use on console, mobile or Windows). Floodgate also automatically handles differences in usernames and skins, and can add a small prefix (such as a "." or "*" before the player's name) to identify Bedrock players on the server. It is essential if you want your server to be truly accessible from any platform.

# Setting up GeyserMC and Floodgate
A step-by-step guide to setting up GeyserMC and Floodgate on a Paper-based network.

## Step 1: Download the required files
To start installing both plugins, download them from their official website.
- **Geyser**: [geysermc.org/download/](https://geysermc.org/download/)
- **Floodgate**: [geysermc.org/download/?project=floodgate](https://geysermc.org/download/?project=floodgate)

## Step 2: Open your hosting panel
I use [XeroHost](https://xerohost.net) to host my network, so the steps below are shown using its web panel.
- 1. Go to your **proxy** server (the one that connects all the servers in your network). We recommend running **Velocity** ([here is why we recommend it](/blog/bungeecordovelocity)) to install GeyserMC.
- 2. Make sure the proxy is stopped so you can safely install the files you downloaded.
- 3. Go to your server's **Files** section.
- 4. Upload the files you downloaded earlier to your proxy's `plugins` folder, usually located at `/home/container/plugins` or similar. The files are typically named `Geyser-Velocity.jar` and `floodgate-velocity.jar` respectively.
- 5. Start the proxy so that the folders where you will configure the plugins are generated.

## Step 3: Configure Geyser and Floodgate
Once your server has started, **2** new folders should appear in your `plugins` folder: **floodgate** and **Geyser-Velocity**. These contain the plugins' configuration files.
- 1. To configure Geyser, you need to open an additional port on your server, usually from the **Network** tab of your hosting panel. In my case, port `25581` was opened, and that is the port Bedrock players will use to connect (if possible, it is recommended to open port 19132, which is Bedrock's default port).
- 2. Now open Geyser's **config.yml** file, usually located at `/home/container/plugins/Geyser-Velocity/config.yml`, and edit the following:

<CodeBlock
    marginBottom="16"
    highlight="2"
    codes={[
      {
        code:
`bedrock:
  port: 25581
  clone-remote-port: false
  motd1: "Geyser"
  motd2: "Another Geyser server."
  server-name: "Geyser"`,
        language: "yml",
        label: "config.yml"
      }
    ]}
/>

Only change the default `port: 19132` value to **your free port**. Be careful not to use your server's main port: it is already in use and can cause errors. Use an open port that is free and not used by any other plugin or program.

- 3. Next, make sure Geyser's **config.yml** also contains the following:

<CodeBlock
    marginBottom="16"
    highlight="2-4"
    codes={[
      {
        code:
`remote:
  address: auto
  port: auto
  auth-type: floodgate
  use-proxy-protocol: false
  forward-hostname: false`,
        language: "yml",
        label: "config.yml"
      }
    ]}
/>

`auth-type:` must be set to **floodgate** for everything to work correctly. I recommend leaving the rest of the file untouched unless you know what you are doing, as you could break the setup and prevent Bedrock players from joining.

- 4. Save the changes and restart the server.
- 5. Now install **Geyser** and **Floodgate** on your other servers (for example Lobby, Survival, Minigames, BoxPvP, etc.) following the same steps. Install the plugins on every server Bedrock players should be able to join.
- 6. Next comes an important step for everything to work: go to the proxy and download the `key.pem` file, usually located in `/home/container/plugins/floodgate`. On your other servers, delete that file from the same folder and replace it with the one you downloaded from the proxy. The `key.pem` file is the key that allows Bedrock players to connect to the Lobby and any other game modes you run. Without it configured correctly, Bedrock players will only be able to reach the proxy and will get a connection error.

Needless to say, whenever you make changes on the proxy or on any other server, restart it so the changes take effect.

## Step 4: Change the Bedrock player prefix (optional)
You can change the prefix shown before a player's name to distinguish Bedrock players from Java players.
This is done in **Floodgate's configuration file**: `/home/container/plugins/floodgate/config.yml`:

<CodeBlock
    marginBottom="16"
    codes={[
      {
        code:
`username-prefix: "B_"`,
        language: "yml",
        label: "config.yml"
      }
    ]}
/>

I recommend using `"B_"` because it is compatible with the **LuckPerms** groups and permissions system.
You can use anything you like, as long as it is short and does not obscure the player's name.
