## ¿Paper o Spigot?

Paper es una versión mejorada de Spigot que añade **más rendimiento**, **parches de seguridad** y **más configuraciones avanzadas**. En 2025, Paper es el estándar recomendado para servidores medianos o grandes.

## 🔧 Plugins esenciales

### 🔒 LuckPerms – Sistema de permisos avanzado

[🔗 luckperms.net](https://luckperms.net)

Es el plugin de permisos más usado. Permite:
- Crear grupos (ej. admin, vip, builder…).
- Asignar permisos de forma jerárquica.
- Gestionar permisos desde consola, en el juego o desde una **web GUI**.
- Compatibilidad total con servidores BungeeCord.

### 📦 EssentialsX – Comandos básicos imprescindibles

[🔗 essentialsx.net](https://essentialsx.net)

Una **colección de comandos útiles** y personalizables:
- `/spawn`, `/home`, `/warp`, `/tpa`, `/back`
- `/msg`, `/kit`, `/nick`, `/clearinventory`
- Soporte para economía, permisos, kits automáticos y más.

Además, EssentialsX incluye módulos extra:
- **EssentialsX Chat** para personalizar el formato del chat.
- **EssentialsX Protect** para proteger zonas básicas.
- **EssentialsX Spawn** para controlar el punto de aparición.

### 🛠 Vault – Soporte universal de economía y permisos

[🔗 Vault](https://www.spigotmc.org/resources/vault.34315/)

Vault no añade comandos, pero **es imprescindible para que otros plugins funcionen**. Actúa como un “puente” para que plugins como Jobs, ShopGUI+ o EssentialsX usen el mismo sistema de economía o permisos.

Sin Vault, muchos plugins no funcionarán correctamente.

### 💬 DiscordSRV – Conecta el servidor a Discord

[🔗 DiscordSRV](https://modrinth.com/plugin/discordsrv)

Permite vincular el chat del juego con un canal de Discord en tiempo real:
- Mensajes del servidor aparecen en Discord.
- Mensajes desde Discord se ven en Minecraft.
- Notificaciones de entrada/salida de jugadores.
- Soporte para comandos personalizados vía Discord.
- Sistema de verificación automática con el plugin **AuthMe**.

Ideal para comunidades activas.

### 👤 TAB – Personaliza el tabulador y los tags

[🔗 TAB (mc-market)](https://www.mc-market.org/resources/20631/)

Permite cambiar:
- El formato del TAB list (colores, rangos, animaciones).
- El nombre encima de los jugadores.
- El scoreboard lateral.
- Animaciones con placeholders.

Compatible con PlaceholderAPI y muy personalizable, incluso con YAML.

### 🌐 Geyser + Floodgate – Jugadores Bedrock en servidores Java

[🔗 geysermc.org](https://geysermc.org)

Con **Geyser** puedes hacer que jugadores de Minecraft Bedrock (móvil, consola, Windows 10) se conecten a tu servidor Java.

**Floodgate** permite que no necesiten cuenta de Java, ideal para servidores mixtos:
- Compatible con Paper, Spigot, Velocity y BungeeCord.
- Posibilidad de usar skins de Bedrock.
- Puedes identificar jugadores Bedrock fácilmente con prefijos (`.nombre` o `[Bedrock]`).

### 🧹 AntiCheat: seguridad frente a trampas

Evita plugins antiguos como NoCheatPlus. Las mejores opciones en 2025 son:

#### ✅ **Grim**
- Open source, muy configurable.
- Compatible con 1.20 y superiores.
- Detección sólida sin muchos falsos positivos.

#### 💎 **Matrix AntiCheat**
- Plugin premium con detección avanzada.
- Soporte activo, constante actualización.

#### ⚠️ Consejo: **Nunca uses más de un anticheat al mismo tiempo**, se anulan entre sí.


## 💡 Bonus: Otros plugins útiles

- **FastAsyncWorldEdit (FAWE)**: edición de mundos a gran escala sin lag.
- **Dynmap** o **BlueMap**: crea un mapa web en vivo del servidor.
- **Plan**: genera estadísticas de uso de jugadores (muy útil para staff).
- **GSit**: para sentarse o tumbarse con animaciones.
- **OpenAudioMc**: música por regiones en el juego.

## ✅ Conclusión

Estos plugins forman una **base sólida y profesional** para cualquier servidor de Minecraft en 2025, ya sea survival, semi-RP, o un network con BungeeCord/Velocity.

Además, esta guía puede servirte como recurso interno para soporte técnico en **XeroHost** o para ofrecer ayuda personalizada a clientes.
