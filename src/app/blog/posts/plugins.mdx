## Paper or Spigot?

Paper is an improved version of Spigot that adds better performance, security patches and more advanced configuration options. In 2025, Paper is the recommended standard for medium and large servers.

## Essential plugins

### LuckPerms

[Download LuckPerms](https://luckperms.net)

The most widely used permissions plugin. It allows you to:
- Create groups (e.g. admin, vip, builder…).
- Assign permissions hierarchically.
- Manage permissions from the console, in game or through a web editor.
- Work seamlessly with BungeeCord and Velocity networks.

### EssentialsX

[Download EssentialsX](https://essentialsx.net)

A collection of useful, customisable commands:
- `/spawn`, `/home`, `/warp`, `/tpa`, `/back`
- `/msg`, `/kit`, `/nick`, `/clearinventory`
- Support for economy, permissions, kits and more.

EssentialsX also includes extra modules:
- **EssentialsX Chat** to customise the chat format.
- **EssentialsX Protect** to protect basic areas.
- **EssentialsX Spawn** to control the spawn point.

### Vault

[Download Vault](https://www.spigotmc.org/resources/vault.34315/)

Vault does not add any commands, but it is essential for many other plugins to work. It acts as a bridge so that plugins such as Jobs, ShopGUI+ or EssentialsX share the same economy and permissions system.

Without Vault, many plugins will not work correctly.

### DiscordSRV

[Download DiscordSRV](https://modrinth.com/plugin/discordsrv)

Links the in-game chat with a Discord channel in real time:
- Server messages appear on Discord.
- Messages sent from Discord appear in Minecraft.
- Player join and leave notifications.
- Support for custom commands through Discord.
- Automatic account verification with the AuthMe plugin.

Ideal for active communities.

### TAB

[Download TAB (mc-market)](https://www.mc-market.org/resources/20631/)

Lets you customise:
- The TAB list format (colours, ranks, animations).
- The name tag above players.
- The sidebar scoreboard.
- Animations with placeholders.

Compatible with PlaceholderAPI and highly customisable through YAML.

### Geyser and Floodgate

[Download GeyserMC](https://geysermc.org)

Geyser allows Minecraft Bedrock players (mobile, console, Windows) to join your Java server.

Floodgate removes the need for a Java account, making it ideal for cross-platform servers:
- Compatible with Paper, Spigot, Velocity and BungeeCord.
- Support for Bedrock skins.
- Bedrock players are easy to identify with prefixes (`.Name` or `B_Name`).

### Anti-cheats

Avoid outdated plugins such as NoCheatPlus. The best options in 2025 are:

#### Grim
- Open source and highly configurable.
- Compatible with 1.20 and above.
- Solid detection with few false positives.

#### Matrix AntiCheat
- Premium plugin with advanced detection.
- Active support and frequent updates.

**Tip**: never run more than one anti-cheat at the same time, as they interfere with each other.

## Bonus: other useful plugins

- **FastAsyncWorldEdit**: large-scale world editing without lag.
- **Dynmap** or **BlueMap**: a live web map of your server.
- **Plan**: player activity statistics (very useful for Staff).
- **GSit**: sit and lay down with animations.
- **OpenAudioMc**: region-based in-game music.

## Conclusion

These plugins form a professional foundation for any Minecraft server in 2025, whether it is a survival server or a network running BungeeCord or Velocity.
